# Chapter 5: Hiragana — M, Y, R, W Rows & N

## M-Row

{{lang:ja}}
ま み む め も
{{/lang}}

- ま (ma) — まち (machi) = town
- み (mi) — みず (mizu) = water
- む (mu) — むし (mushi) = insect
- め (me) — めがね (megane) = glasses
- も (mo) — もり (mori) = forest

## Y-Row

Only three characters exist — yi and ye don't exist in modern Japanese:

{{lang:ja}}
や ゆ よ
{{/lang}}

- や (ya) — やま (yama) = mountain
- ゆ (yu) — ゆき (yuki) = snow
- よ (yo) — よる (yoru) = night

These are also used as small characters to create combination sounds:

{{lang:ja}}
きゃく
しゅくだい
ちょっと
にゅうがく
りょこう
{{/lang}}

- きゃく (kyaku) = guest
- しゅくだい (shukudai) = homework
- ちょっと (chotto) = a little
- にゅうがく (nyuugaku) = enrollment
- りょこう (ryokou) = travel

## R-Row

The Japanese "r" is a light tap — somewhere between English "r", "l", and "d":

{{lang:ja}}
ら り る れ ろ
{{/lang}}

- ら (ra) — らいねん (rainen) = next year
- り (ri) — りんご (ringo) = apple
- る (ru) — さる (saru) = monkey
- れ (re) — れきし (rekishi) = history
- ろ (ro) — ろく (roku) = six

## W-Row

Only two characters survive in modern Japanese:

{{lang:ja}}
わ を
{{/lang}}

- わ (wa) — わたし (watashi) = I, me
- を (wo/o) — object marker particle, always pronounced "o"

Example:

{{lang:ja}}
水を飲む
{{/lang}}

(mizu o nomu = drink water)

## The Lone N

The only consonant that stands alone with no vowel attached:

{{lang:ja}}
ん
{{/lang}}

This character changes sound depending on what follows:

- Before b, p, m it sounds like "m": しんぶん (shimbun) = newspaper
- Before n, t, d it sounds like "n": あんない (annai) = guidance
- Before k, g it sounds like "ng": まんが (manga) = manga
