# Official Exam Format (2025 Guide - Universidad de Antioquia)

Source: "Instructivo para la presentación de la prueba escrita de conocimientos"
Downloaded from Cancillería, 20 pages.

## KEY FINDING: The exam IS multiple choice (opción múltiple con única respuesta)
- This confirms our ExamHelper format is correct!
- Each question has 4 options, only 1 is correct
- Mark answer by filling a circle on the answer sheet
- Use #2 pencil only

## Passing Requirements (Points de Corte)

You must pass ALL modules individually. No accumulation across attempts.

| Área | Minimum correct answers | Minimum score (0-100) |
|------|------------------------|----------------------|
| Constitución Política | 12/20 | 60% |
| Historia Patria | 8/20 | 40% |
| Geografía | 11/20 | 55% |
| Cultura | 8/20 | 40% |
| Lengua Castellana | 4/10 | 40% |

**CRITICAL**: Must get POSITIVE in ALL modules to pass. Failing even 1 module = NOT APPROVED.

- Must stay minimum 1 hour
- Materials allowed: #2 pencil, pencil sharpener, eraser, ID documents only
- NO electronics, phones, smartwatches, notebooks, etc.
